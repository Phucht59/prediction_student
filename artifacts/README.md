# Scientific evidence

Thư mục evidence được tổ chức theo bộ dữ liệu thay vì theo mã phase nội bộ:

- `student_mat/`: estimator validation, model comparison, prediction freeze, recommendation và final closure.
- `student_por/`: independent evaluation và transfer evidence chính thức.
- `oulad/`: baseline, tuning, temporal analysis và final ensemble.
- `archive/`: smoke, superseded, diagnostic và historical evidence; không đủ điều kiện headline.

Các file bên trong bundle được giữ nguyên byte và tiếp tục được xác minh bằng checksum. Tên run kỹ thuật cũ vẫn có thể xuất hiện trong nội dung provenance vì đó là định danh tại thời điểm evidence được tạo.
