# Paired bootstrap comparison

This is a supplementary post-hoc analysis of uncertainty in performance gaps,
not a model-selection step. It was not run because the evidence bundle contains
prediction-level rows only for CNN–BiLSTM. `baseline_results.csv` contains only
aggregate values for the G2 rule and HGB, so record-paired resampling of the
same 79 records cannot be reconstructed without inventing predictions. No
locked-test predictions were regenerated.
