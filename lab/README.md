# Research laboratory

`lab/` contains historical experiments, negative results, architecture diagnostics and optional future evaluation material. Nothing in `lab/` supersedes canonical final results.

The repository currently retains several legacy paths outside `lab/` because they are referenced by frozen V5.1/V6/V6.2 replay contracts, manifests, or checksums. They must remain in place until a separately versioned migration can preserve those contracts. This directory is therefore the clear home for new non-authoritative research material and for any future migration that can prove path-safe reproducibility.

- `experiments/`: non-selected search and experimental work.
- `diagnostics/`: controlled analyses and negative results.
- `historical/`: archived contextual material.
- `future_evaluation/`: optional human/expert evaluation work, which is not a current thesis blocker.
