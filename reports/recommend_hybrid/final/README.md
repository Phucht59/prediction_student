# Final recommendation reports

This is the canonical report set for the released recommendation model on `main`.
The reports are copied from the immutable scientific release commit
`17b519b22e8b69c875d27547d097e6d3b76bc404` without changing their scientific
results.

Recommended reading order:

1. `FINAL_RELEASE_SUMMARY.md`
2. `FINAL_MODEL_ARCHITECTURE_AND_PIPELINE.md`
3. `PANEL_B_FINAL_HELDOUT_RESULTS.md`
4. `FINAL_SCIENTIFIC_AUDIT.md`
5. `FINAL_IMPLEMENTATION_STATUS.md`
6. `FIVE_EBM_MODEL_REPORT.md`

Panel-A values are development metrics. `PANEL_B_FINAL_HELDOUT_RESULTS.md` contains the
one-shot final held-out results and must not be used for post-heldout tuning.
