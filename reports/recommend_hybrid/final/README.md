# Final recommendation reports

This directory is the canonical report surface for the released recommendation
module. These reports are byte-identical copies of the final scientific reports
created at release commit `17b519b22e8b69c875d27547d097e6d3b76bc404`.

Read in this order:

1. `FINAL_RELEASE_SUMMARY.md`
2. `FINAL_MODEL_ARCHITECTURE_AND_PIPELINE.md`
3. `PANEL_B_FINAL_HELDOUT_RESULTS.md`
4. `FINAL_SCIENTIFIC_AUDIT.md`
5. `FINAL_IMPLEMENTATION_STATUS.md`
6. `FIVE_EBM_MODEL_REPORT.md`

`PANEL_B_FINAL_HELDOUT_RESULTS.md` contains the one-shot final held-out metrics.
Panel-A development metrics must not be presented as final results.

The older `reports/recommend_hybrid_v2/` path is retained as historical audit
lineage; new documentation should link to this canonical directory.
