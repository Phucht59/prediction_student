# Phase 4 limitations

The retained Phase 2 labels are weak-supervision outputs, not expert relevance labels.
The audit establishes that target class is strongly entangled with action/stage policy
and LF conflict.  Training a flexible model on those targets risks an action-prior
shortcut and cannot establish a student-specific recommendation effect.

Accordingly, no final deployment checkpoint, final registry, or educational-effect
claim is produced.  A valid next release requires independently adjudicated,
pre-cutoff student-action relevance cases with enough CONDITIONAL examples across
actions and stages.  This is not a request to alter Phase 2 labels.
